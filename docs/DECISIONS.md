# DECISIONS — decision log

Important project decisions: context, options, decision, rationale, trade-offs, consequence. Structural ones have an ADR
in `adr/`; smaller ones live only here. There is no "universally best architecture": every decision is grounded in the
context (1 developer, C#/.NET portfolio, modular monolith, cost-aware, honest).
